# Contributing to agentshield-vscode

Thank you for your interest in contributing to **agentshield-vscode**!

## Getting Started
1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/<your-username>/agentshield-vscode.git
   cd agentshield-vscode
   ```
3. **Create a topic branch**:
   ```bash
   git checkout -b feat/your-feature-name
   ```

## Commit Conventions
We follow [Conventional Commits](https://www.conventionalcommits.org/):
- `feat:` New features or public APIs
- `fix:` Bug fixes
- `docs:` Documentation improvements
- `test:` Adding or updating tests
- `chore:` Dependency or build system updates

## Pull Request Checklist
- Code adheres to existing formatting and linting rules.
- All test suites pass locally.
- Keep PRs focused on a single change.
- Link related issues in the description using `Fixes #<issue-number>`.
