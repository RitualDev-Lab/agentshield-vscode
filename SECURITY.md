# Security Policy & Vulnerability Disclosure

RitualDev Lab takes the security of the **AgentShield VS Code / Open VSX Extension** (`ritualdev-lab.agentshield-defense`) seriously.

## Supported Versions

| Version | Supported | Minimum Engine | Response Target |
| :--- | :---: | :---: | :---: |
| **>= 0.2.2** | Active | VS Code >= 1.85.0 | Critical & High: < 24 Hours |
| < 0.2.2 | End-of-Life | — | Upgrade to >= 0.2.2 |

## Reporting a Vulnerability

Please **do not** open public GitHub issues for undisclosed security vulnerabilities.

- **GitHub Private Security Advisory (Preferred)**: [Report a Security Advisory](https://github.com/RitualDev-Lab/agentshield-vscode/security/advisories/new)
- **Email**: `security@ritualdev.in` with subject `[SECURITY VULNERABILITY] ritualdev-lab.agentshield-defense (agentshield-vscode)`

## Compliance & Control Alignment

- **Status**: SOC 2 Type II & ISO 27001 Control-Mapped Architecture (**Self-Attested Readiness; Formal Independent Audit Planned**).
- **Trust & Control Mapping Portal**: [https://ritualdev.in/trust](https://ritualdev.in/trust)
